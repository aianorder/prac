# prac · 仕訳練習ノート

日本語の仕訳問題を生成し、ブラウザーで練習・採点できる小さな Web アプリです。問題用紙と解答の印刷、CSV 出力にも対応しています。

**ビルド不要・実行時の依存パッケージなし・ログイン不要。** 外部 API、解析タグ、外部フォントは使いません。

## できること

- 28 種類の出題テンプレートから、金額を変えた問題を生成
- 日常の取引・商品売買・資金の取引・決算整理の 4 分野
- 基礎 / 応用 / 両方を選択し、5・10・20・30 問を作成
- 借方 / 貸方の複数行入力、1 問ずつ / まとめて採点
- 貸借一致の確認と、勘定科目・金額を含めた正誤判定
- 模範解答と考え方の表示
- 同じ問題コードと設定で、同じ問題セットを再現
- 問題だけ / 解答つきの印刷・PDF 保存と CSV 出力
- このブラウザーへの学習内容の自動保存
- スマートフォンに対応したレイアウト

## すぐ使う

リポジトリをダウンロードし、**`index.html` をブラウザーで開くだけ**で使えます。`app.js`、`engine.js`、`styles.css` は同じフォルダーに置いてください。

ローカルサーバーで開く場合は Node.js 22 以降で次を実行します。`npm install` は不要です。

```sh
npm start
```

表示される `http://127.0.0.1:4173` を開きます。開発用サーバーはその PC 内からのみアクセスできます。ポートは環境変数 `PORT` で変更できます。

### 練習の流れ

1. 難易度・出題範囲・問題数を選び、「問題をつくる」を押します。
2. 各問の借方・貸方、勘定科目、金額を入力します。金額はカンマなしの半角整数です。
3. 複合仕訳は「借方を追加」「貸方を追加」で行を追加します。余分な行は削除してください。
4. 「採点する」または「まとめて採点」で確認します。
5. 「解答と考え方を見る」で仕訳の理由を確認します。

問題コードが空欄なら新しい問題を生成します。問題の上部に表示されたコードを使うと、**同じアプリバージョン・難易度・分野・問題数**で同じ問題を作れます。問題を変える前には入力内容を置き換えるか確認します。

### 印刷と保存

「印刷・保存」から問題だけ、または解答つきで印刷します。PDF はブラウザーの印刷画面で保存先として選びます。端末やブラウザーによって印刷・ダウンロードの操作は異なります。

CSV は UTF-8 BOM 付きで、Excel 等で日本語を扱いやすい形式です。「解答つき CSV 保存」は模範解答を含みます。CSV は問題セットの出力用で、入力途中の答案を再読み込みする機能はありません。

## 会計処理の前提と範囲

- 簡略化した商業簿記の仕訳練習です。特定の検定試験の公式教材ではありません。
- 金額は円単位。消費税、法人税等は考慮しません。
- 商品売買は三分法。販売時には売上原価の仕訳をしません。
- 減価償却は問題文で指定する定額法・間接法、残存価額 0 円です。
- 給料の問題では源泉徴収・社会保険料等を省略します。
- 採点にはアプリに用意した勘定科目を使います。別名の科目や他の会計処理方法の答案は自動では受け付けません。
- 同じ側・同じ勘定科目の分割記入は合算して採点します。行の順番は問いません。
- 期首・期末商品の問題は、指示どおり 2 つの整理仕訳を相殺せず 4 行で記入します。
- 正誤は勘定科目と金額で判定します。貸借合計が一致するだけでは正解になりません。

**実務上の会計・税務判断に使用しないでください。** 個別の取引は法令・会計基準・契約条件などに応じて専門家に確認してください。

## データについて

入力内容は `localStorage` に保存され、アプリから外部へ送信しません。同期・アカウント機能はありません。保存先は端末・ブラウザー・URL ごとに異なります。プライベートブラウジング、ブラウザーの設定、`file://` の扱いによって保存できない場合は画面に案内を表示します。保存できない場合でも練習と出力は利用できます。

「入力をリセット」は現在の問題の答案と採点結果を初期化します。保存データを完全に消すにはブラウザーのサイトデータを削除してください。外部ホスティングを使う場合、ページ取得時のアクセス情報はホスティング事業者に送られます。

## GitHub Pages で使う場合

このリポジトリを GitHub にアップロードしただけでは Web サイトは公開されません。公開を希望する場合、リポジトリ所有者が GitHub の **Settings → Pages** から、`main` ブランチの `/ (root)` を公開元に設定できます。公開設定が完了するまではサイトの URL は利用できません。GitHub のプラン・リポジトリ公開範囲によって利用条件が異なります。

## 開発とテスト

```sh
npm run check
npm test
```

実行時と自動テストに外部パッケージは不要です。テストでは再現性、分野・難易度フィルター、5,000 問の貸借一致、採点の境界値、CSV のエスケープと数式注入対策を検証します。GitHub Actions のテスト定義も含みます。

```text
index.html               画面構成
styles.css               画面・モバイル・印刷用スタイル
app.js                   入力、採点、保存、出力の UI
engine.js                問題生成と採点の純粋なロジック
server.cjs               開発用ローカルサーバー
 tests/engine.test.cjs    問題生成・採点・CSV の自動テスト
.github/workflows/test.yml  GitHub Actions の自動チェック
```

### エンジン API

ブラウザーでは `window.PracEngine`、Node.js では `require('./engine.js')` で利用できます。

```js
const { generateSet, gradeAnswer, toCsv } = require('./engine.js');
const set = generateSet({
  count: 10,              // API は 1〜50
  difficulty: 'all',      // basic / applied / all
  category: 'all',        // daily / trade / finance / closing / all
  seed: 'lesson-01'       // 空文字なら自動作成
});
const result = gradeAnswer(set.problems[0], [
  { side: 'debit', account: '仕入', amount: 10000 },
  { side: 'credit', account: '買掛金', amount: 10000 }
]);
const csv = toCsv(set, { includeAnswers: true });
```

金額は文字列ではなく、正の安全な整数を渡します。上の答案は書式の例であり、生成された第 1 問の正解とは限りません。テンプレートを追加する場合は `engine.js` の登録処理に追加し、対応する勘定科目とテストも更新してください。
